# fullseye-media2026q4

[Fullseye](https://github.com/furuse-kazufumi/fullseye) の記事(Qiita など)が読む画像・動画の置き場です。
2026 年 10〜12 月ごろに書いた記事の素材を入れます。

Media assets (images and short clips) referenced by articles about
[Fullseye](https://github.com/furuse-kazufumi/fullseye). Roughly Q4 2026.

## 使い方

記事からは raw URL で読みます。

```
https://raw.githubusercontent.com/furuse-kazufumi/fullseye-media2026q4/main/<記事の名前>/<ファイル名>
```

## 決まり

- **一度置いたファイルは、動かさない・消さない・名前を変えない。** 公開済みの記事の画像が欠けます。差し替えるときは、新しい名前で足して記事の URL を書き換えます。
- 素材は Fullseye の op と PoC の実出力です。手で描いた絵や、他の道具の出力は置きません。
- 第三者のデータに由来し、再配布できない素材は置きません。
- 1 ファイルの大きさの目安は、GIF 3 MB・PNG 6 MB までです。
- 四半期は目安です。この repo が大きくなったら、次の repo(`fullseye-media2027q1` など)を作ります。素材を repo の間で移すことはしません。

## 置き方

```
<記事の名前>/<ファイル名>
```

記事の名前は、記事の中身を表す短い英小文字(`-` 区切り)にします。
